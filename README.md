# Mi Salud

App web sencilla para el iPhone: comidas y calorías, agua, pasos, recetas asturianas ligeras y ejercicios de fuerza adaptados a la osteoporosis.

- Los datos personales se guardan **solo en el teléfono** (localStorage). No hay servidor ni se envía nada.
- Funciona sin conexión una vez abierta.
- Los ejercicios son orientativos: consulta siempre a tu médico o fisioterapeuta.
